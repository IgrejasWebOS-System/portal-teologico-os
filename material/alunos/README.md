# Material — Alunos

Capturas de tela do fluxo completo de matrícula de aluno, a partir do link
gerado pelo professor (ou da inscrição pública), até o acesso às aulas.

Fluxo esperado (ajustar depois de rodar o teste real):
1. `/matricula-turma/[token]` — link recebido do professor, formulário de
   matrícula
2. Tela de sucesso da matrícula
3. E-mail de convite (⚠️ avisar sobre a pasta de Spam, mesmo caso dos
   professores)
4. `/definir-senha` — criar senha e entrar
5. `/completar-cadastro` — ficha completa do aluno
6. `/completar-cadastro/pagamento` — pagamento inicial (parcelas, forma de
   pagamento)
7. `/portal` — acesso à área do aluno / às aulas

Salvar as capturas aqui numeradas (`01-...png`, `02-...png`, ...).
