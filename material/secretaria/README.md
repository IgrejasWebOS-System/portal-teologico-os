# Material — Secretaria

Capturas de tela dos fluxos administrativos do dia a dia da secretaria.
Ainda por definir quais fluxos entram primeiro — candidatos:

- `/admin/inscricoes` — aprovar inscrição pública, gerar matrícula
- `/admin/matriculas/nova` — matrícula direta
- `/admin/matriculas/[id]` — conferência de mensalidades, edição de matrícula
- `/admin/matriculas/ficha-rapida` — ficha rápida de matrícula
- Configurações → Professores, Cargos, Líderes de Setor

Salvar as capturas aqui numeradas (`01-...png`, `02-...png`, ...), agrupadas
por fluxo se forem vários (pode usar subpastas, ex.
`inscricoes/01-....png`).
