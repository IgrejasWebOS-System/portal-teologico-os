# Material — Professores

Capturas de tela do fluxo completo de cadastro de professor, do link
público até a geração do link de matrícula pra turma.

Fluxo esperado (ver roteiro completo combinado no chat):
1. `/cadastro-professor` — formulário público (nome, CPF, telefone, e-mail)
2. Tela de sucesso com o código de professor gerado
3. E-mail de convite (⚠️ avisar sobre a pasta de Spam)
4. `/definir-senha` — criar senha e entrar
5. `/completar-cadastro` — ficha completa (campo/setor/igreja, dados
   pessoais, documento, endereço)
6. `/professor` — área do professor, "Vincular a turma já existente"
7. Link de matrícula gerado, pronto pra copiar e enviar aos alunos

Salvar as capturas aqui numeradas (`01-...png`, `02-...png`, ...).
